# Prediksi Suhu Harian Stasiun Ahmad Yani (2025)

Proyek ini melakukan analisis time series forecasting untuk memprediksi suhu harian menggunakan algoritma **Support Vector Regression (SVR)** dengan Kernel Linear dan RBF.

## File dalam Repository
- `St. Ahmad Yani-SVR.R`: Skrip utama pemodelan R.
- `St. Ahmad Yani 2025.xlsx`: Dataset suhu harian.
